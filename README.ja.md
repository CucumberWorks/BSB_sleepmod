# BSB Sleep Mod

[English](README.md) | [简体中文](README.zh-CN.md) | 日本語

睡眠時の快適さを追求した BSB 用の改造パーツです。

- 顔への圧迫感を軽減
- 水洗いできるフェイスインターフェース
- 改造パーツはすべて 3D プリントでき、交換も簡単
- 優れた通気性

![BSB 睡眠用改造パーツ](docs/images/bsb-sleep-mod.webp)

[元の投稿](https://x.com/cucumberworks/status/2104484445499887772)

## 用意するもの

- AMVR 製 Quest 3 用フェイスインターフェース
- 面ファスナーテープ
- 幅 25 mm の面ファスナーストラップ
- 瞬間接着剤
- 3 mm の磁石

## プリントするパーツ

各 STL ファイルを 1 個ずつプリントしてください。左右のミラー版を同梱しています。

| パーツ | ファイル | 推奨素材 |
| --- | --- | --- |
| 本体 | [クッションブラケット](stl/cushion_bracket.stl) | ナイロンまたは PETG。高強度プリセットと高いインフィル密度を使用 |
| 遮光パーツ | [左](stl/lightblocker_L.stl) / [右](stl/lightblocker_R.stl) | TPU |
| アーム／ストラップアダプター | [左](stl/strap_adapter_L.stl) / [右](stl/strap_adapter_R.stl) | TPU |
