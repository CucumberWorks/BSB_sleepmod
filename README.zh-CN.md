# BSB Sleep Mod

[English](README.md) | 简体中文 | [日本語](README.ja.md)

以舒适睡眠为目标的 BSB 改装方案：

- 减轻面部压迫感
- 面罩可水洗
- 改装部件均可 3D 打印，方便更换
- 出色的通风性

![BSB 睡眠改装](docs/images/bsb-sleep-mod.webp)

[原帖](https://x.com/cucumberworks/status/2104484445499887772)

## 所需材料

- AMVR Quest 3 面罩
- 魔术贴胶带
- 25 mm 宽的魔术贴绑带
- 瞬间胶
- 3 mm 磁铁

## 打印部件

每个 STL 文件各打印一件。已包含左右镜像部件。
